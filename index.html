Syllabus

1 Introduction to Python

Python: Setting up environment, basic python commands, creating python scripts, conditions, loops, list, dictionary, user defined functions, introduction to anaconda, working with numpy, pandas, matplotlib.

Mathematics for machine learning: Vectors, matrices, linear equations, mean, median, mode, standard deviation, variance, probability, correlation, regression, handling and representing data.

2 Machine Learning

Definition and history of AI, defining machine learning, applications of ML, issues and challenges in ML, types of ML, basics of supervised learning, prediction, classification, understanding datasets, feature selection, feature normalization, data cleaning, training, testing and validation sets.

Different models of supervised learning, hyper parameters, measuring performance, accuracy, loss, underfitting and overfitting.

Basics of unsupervised learning, different models of unsupervised learning.

3 Neural Network

Understanding the biological brain, defining artificial neural networks (ANN), applications of ANN and DL, defining and building a perceptron, feed forward, back propagation, single-layer and multi-layer ANNs, building an ANN model, activation and loss functions, compiling and evaluating a model.

Convolutional neural networks (CNN), understanding convolutions, pooling, building and fitting CNN models, evaluating model performance.

Recurrent neural networks (RNN), basic architecture, applications of RNN, building and fitting RNN models, evaluating model performance. Long short term memory networks (LSTM), LSTM architecture, understanding LSTM, building LSTMs.
